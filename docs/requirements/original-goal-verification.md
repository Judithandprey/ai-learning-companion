# 原有学习伙伴目标：直接验证案例

本文是[主规格](../requirements.md)的规范性验收细化，依据原始规格提交 `9e1163b97972bf1a3ce492d271f269691db67c65` 的 R01–R50，并与当前 R51–R59、[做题陪伴规范](problem-solving-companion.md)共同执行。这里的 `V-*` 是具名验证入口，不是新增 R 或 A，不替换主规格的需求、验收编号、能力关卡或阶段退出条件。

**本文全部案例当前均为未运行／未验收。** 任务卡、设计向量、fixture、单元测试、编译结果、账号登录及消息回执均不能直接把这些产品场景标为通过。已有局部证据可以关联，但必须写清真实运行范围、剩余步骤和失败。执行基线、分工及调度见[任务板](../tasks.md)，覆盖关系见[需求追踪](../requirements-traceability.md)。

本轮笔迹显示、笔记／草稿分类及作业去向的提问均已有实际答案，见[用户意图与决定](intent-and-decisions.md)。本文不重开这些问题，也不重写其中的 `INTENT-INK-MODES`、`INTENT-NOTE-CLASSIFICATION`、`INTENT-ANSWER-PROMPT`、`INTENT-HOMEWORK-CHOICE`、`INTENT-FAITHFUL-EXPORT`；涉及原屏幕笔迹和归档时须交叉执行这些案例及 A26–A28/A44–A46。

## 执行与报告规则

- 每例记录精确提交、设备／OS、应用及模型版本、网络、来源授权、实际样本与独立参考答案、步骤记录、失败样例和产物位置。真实课程／账号／设备与合成数据分别标注；不把一个入口的结果移用到另一平台。QA 独立核对行为、语义及原始证据，总工决定阶段集成状态，不以模型彼此同意代替证据。
- 一例横跨多个阶段时，分别报告已完成切片与未完成部分。P0 的能力调查和确定性测试只能准备证据；P1 仍包含主规格规定的日历、持久来源、真实语音、本地笔记及真实单题闭环；P2–P4 的剩余目标不会因最小探针通过而消失。
- 只沿用原主规格 §11 的数值目标。未指定的长会话时长、容量压力点、采样策略、提示去重间隔和评价分界均须标为**工程默认**，执行前说明选择理由，报告实际分布及失败，不能写成用户指定或已达成。数值目标仍是首轮工程目标，不是对任意环境的保证。
- 通过定义须同时满足正向行为及本例负例，不仅检查字段或固定文本。来源未知、平台不支持和测试未运行分别记录；有证据的 unsupported 不等于产品行为 PASS，仍须保留需求缺口及已验证备选。
- 本文不授予新的外部行动权限。真实供应商调用、工作 Agent 行动和外部写入使用已授权连接及明确任务范围；付费调用前验证预算控制。测试记录不保存凭据，不要求模型内部思维链。原始对话、用户墨迹与来源不能被摘要替代；明确删除及撤权按原规格处理。
- 普通看课的可跳过主动教学、授权监督、跨天同伴记忆和自主备课继续有效。“让我自己试”约束当前做题范围的帮助披露，不是取消整个产品的主动能力；该范围内监督、缓存、语音和补图也不得绕过限制。明确结束、暂停、撤权仍按各自范围执行。

<a id="V-DailyResume"></a>

## V-DailyResume — 每日回来继续实际课程

- **关联：** R01–R03、R06、R08–R10、R43–R45；既有 A01–A03/A05/A06/A17/A23–A25，手写与原位路径另联 A26–A28/A44–A46。关卡 G1/G2/G4，不以本例替代它们。
- **负责人／阶段：** iOS 主责日常流程，backend 负责连接、来源和恢复，learning 负责上下文，web 负责支持网页；QA 独立验收。P1 完成真实 iPad 日常闭环，P3 补齐日历持续后台同步。
- **前置：** 可操作的真实 iPad、实际课程及独立自学项目；首次连接所需授权已完成，保存稳定课程 URL，按实际可用权限连接 Calendar／Canvas。来源不可用时保留具体状态，不能以空壳项目替代课程。
- **步骤：** 首次进入课程，点读并静音显示解释，选择深入方向，进行真实语音追问，保存本地 note 与原出处；正常关闭后在次日重新打开，通过日历及实际学习进度回到课程位置。另运行无 Canvas／无教师／无正式大纲的自学项目，并分别模拟正常授权刷新与撤权。
- **成功与负例：** 日常不要求重发已保存课程链接、材料或全部背景；必要系统授权确认仍如实显示。来源、语音讨论、学习进度与计划各自正确恢复；撤权后不冒充仍能读最新材料。只有“圈选→fixture 卡片→保存→重启”不足以通过。若 P1 笔记仅含 AI 文本须明示尚无可编辑手写，已启用的用户墨迹须另验保存；画布备选不使 R59/A44 通过。
- **产物：** 首次及次日真机操作记录、来源及 note 版本对照、日历实例与实际进度、刷新／撤权证据、支持路径与未完成项清单。
- **状态：** 未运行／未验收。

<a id="V-ModelSwitchContext"></a>

## V-ModelSwitchContext — 换模型仍是同一位学习伙伴

- **关联：** R04、R27、R30、R32、R42；兼容 R57/R58，既有 A10/A20/A38/A40。G4 是可用连接前置，G6 是检索能力关联项。
- **负责人／阶段：** learning 主责，backend 负责统一身份、原档案和偏好，iOS/web 负责切换体验；QA 独立验收。P1 验证可用模型间连续性，P2 深化长期记忆，P3 验证自动分流中的连续性。
- **前置：** 已授权且实际可调用的不同模型路径；包含早期细节、当前选区、用户目标、课程进度、note、更正及临时语言覆盖的真实档案。不可用模型明确列出，不能用改模型标签的 mock 代替。
- **步骤：** 在当前模型开展学习并保存原记录，切换模型后继续未完成讨论；追问早期细节及已更正解释；重启后再次切换，并验证当前问题的临时语言覆盖结束后恢复持久偏好。
- **成功与负例：** 来源、个人目标、当前问题、帮助历史及最新更正保持连续，不重新要求用户讲全部背景；不串其他用户／课程或恢复旧诊断。跨模型源文和用户原话不被改写，临时中文要求不永久覆盖 English-first。摘要相似或使用同一登录账号不算连续记忆证明。
- **产物：** 实际模型请求／响应及版本、切换前后检索引用、档案哈希、更正与偏好范围对照、遗漏及错误来源样例。
- **状态：** 未运行／未验收。

<a id="V-WorkAgentActualAction"></a>

## V-WorkAgentActualAction — 工作 Agent 的真实行动和中途指导

- **关联：** R05、R32、R38；既有 A15 覆盖工作屏上下文，A17 覆盖连接失效，A10 覆盖记忆连续；这些 A 的局部通过均不能代替本例的实际行动验证。G3/G4 为平台及连接前置。
- **负责人／阶段：** web 主责 Windows 体验，learning 负责官方 Agent 适配与任务理解，backend 负责任务／权限／取消状态，总工协调接口；QA 独立验收。P4；P0 的登录或连接调查不算完成。
- **前置：** 实际 Windows 环境、受支持的官方 Codex／Claude Code 连接路径和明确授权的无破坏性测试工作区；记录每个供应商实际支持与不支持的操作。
- **步骤：** 接入一个已经运行且保留原工具／任务上下文的工作 Agent，再在产品中下达有可核验产物的新任务；分别观察真实 Agent 工具行动并询问它当前在做什么；中途改变目标或约束，检查后续行动及产物；再分别测试暂停、继续或实际支持的等效控制、取消及断线后核实状态。重开后追问任务缘由和历史决定。
- **成功与负例：** 指令影响真实任务，解释引用当前实际工具／文件／任务状态；取消有实际停止或明确的供应商未确认状态，不仅改变 UI。仅登录、观看屏幕、生成任务建议或伪造工具日志均不通过；不支持的控制不假称执行，迟到结果不覆盖取消后的新指令，不越过用户授权修改外部生产目标。
- **产物：** 官方连接能力表、任务和工具回执、允许公开的工作区差异／产物、调整前后行动、取消竞态及断线记录、跨天任务记忆证据。
- **状态：** 未运行／未验收。

<a id="V-CacheProvenanceLatency"></a>

## V-CacheProvenanceLatency — 预生成解释的来源、命中与有效延迟

- **关联：** R10、R12、R13；兼容 R53/R57，既有 A01/A02/A04/A20/A34。
- **负责人／阶段：** learning 主责预生成与匹配，backend 负责版本／失效，iOS/web 负责最终显示及计时；QA 独立验收。P1 验证基础点读，P2 扩展预备内容和理解适配。
- **前置：** 真实课程及可追溯原材料；准备尚未预填候选／答案的新片段，保留用户当前学习位置、知识／讨论依据，以及一组已有预备内容和无缓存对照。预先标注应可复用和应拒用的请求集。统计命中的分母及排除理由在运行前确定，选择是工程默认。
- **步骤：** 先观察系统根据实际课程位置、材料及个人理解状态主动预测／选择可能点选的候选概念，在用户点选前自动生成内容，再由用户随后点选并取用；保存候选依据及可核实的生成完成先于点选的事件顺序，可联动 V-AutonomousPreparationCycle。再对预备内容和未预备内容分别点读；加入相同术语但不同章节／视频位置、用户知识变化、更正、当前问题语言覆盖变化、探索／提示许可变化及切题期间迟到响应；记录最终有效卡片及完整内容的出现时间。
- **成功与负例：** 必须观察到候选预测和提前生成的真实过程；人工预塞答案、点选后才生成或只证明已有 cache 命中均不能完成 R12。提前生成仍不授权提前展示。命中需同时符合来源位置、当前理解和允许帮助程度，不能靠同词缓存串课或提前泄题。报告真实命中率／未命中原因。沿用原 §11：本地预生成解释 P95≤300ms；未命中状态≤150ms，普通短解释首段有效内容 P50≤3s、P95≤6s；复杂推理单列分布。另报完整回答延迟，不新增其硬阈值；进度条和空泛开场不算有效解释，cache_hit 不等于已获准展示。
- **产物：** 候选概念及其课程／个人状态依据、生成任务和带来源版本的产物、生成完成与点选的时间／因果顺序证据、请求集及独立来源标签、缓存键／版本决策证据、端到端时间记录、命中与未命中分母、延迟分布和失效／错绑／披露负例。
- **状态：** 未运行／未验收。

<a id="V-FutureCourseEvidence"></a>

## V-FutureCourseEvidence — 说明后续用途必须有课程证据

- **关联：** R11、R14、R15；既有 A04/A19，A39 约束直观教学形式。
- **负责人／阶段：** learning 主责，backend 提供材料版本，QA 独立核对教学内容。P1 建立证据边界，P2 完整跨章节教学。
- **前置：** 成对准备已取得真实后续课程材料与未取得后续课程材料的情形，保留早期章节、用户当前知识及其他课程的同名概念作为干扰。
- **步骤：** 在早期概念处询问“为什么学、以后在哪里用”，再在后期出现该概念时继续讨论；对无后续材料的课程问同样问题，变更或撤销来源后复查。
- **成功与负例：** 已知后续内容须指向实际章节／材料版本并解释关系；未知时可讲一般学科用途，但清楚区别于这门课的实际安排，不编造教师计划。深度适合当前阶段，不硬截断必要推导；旧材料关系与当前版本分开，其他课程的类似术语不能充当本课程后续证据。
- **产物：** 真实课程来源清单、前后章节引用、成对回答、独立正确性核对及无来源／错课程负例。
- **状态：** 未运行／未验收。

<a id="V-ReuseEvidence"></a>

## V-ReuseEvidence — 成熟工具的实际复用边界

- **关联：** R18；既有 A 无单项直接验证工程复用，所复用功能仍须按其对应 A 验证，不能借其他 A 的成功代替本检查。
- **负责人／阶段：** 总工主责，各模块提供证据，QA 核对声称的能力；P0 选型记录，P1–P4 随实际交付复核。依赖及共享配置仍归总工。
- **前置：** 候选已有 SDK、库、官方连接器、提示／交互方案与实际需要解决的问题，明确许可、版本和接入边界。
- **步骤：** 对拟采用组件先验证最小实际任务，再记录复用内容、仍由项目承担的部分及合理替代路线；在所属模块的真实行为测试中复核，并在版本或支持范围变化后更新记录。
- **成功与负例：** 采用成熟能力须有实际收益和可复核边界，不为复用而强行改变用户流程，也不无依据从零重造已有组件。不以安装依赖、复制示例或列出品牌宣称接通；组件不提供的权限、可靠性和端到端效果仍由本项目验证。
- **产物：** 简洁选型／ADR、许可与版本依据、最小接入结果、对应模块验收链接及剩余责任表。
- **状态：** 未运行／未验收。

<a id="V-SupervisionGoalHistory"></a>

## V-SupervisionGoalHistory — 有依据的监督与目标历史

- **关联：** R19、R21、R23–R25、R41；兼容 R53，既有 A07/A13/A14/A22。
- **负责人／阶段：** learning 主责判断与沟通，backend 负责目标、计划及互动历史，iOS/web 负责状态及反馈；QA 独立验收。P1 保存目标及基本历史，P3 完成持续监督。
- **前置：** 经用户确认的目标和允许的监督范围、实际进度及相关课程依据；标注相关先修学习、无关分心、信息不足、用户暂不回复等不同情形。
- **步骤：** 学习中顺便表达长期目标；跨天继续，在适当时机联系目标和进度；切到相关先修、无关内容及不可见状态；另从原目标转向新目标，结合实际进度、日程和截止时间讨论理由，信息不足时短问，不将畏难猜测当事实；对提醒作出纠正、拒绝或不回应；后续再次遇到同类困难，检查是否记得前因、用户偏好和之前反馈，并提供可执行的下一步。
- **成功与负例：** 监督基于可说明的证据而非 App 名称或单次停顿；相关查阅不误判走神，未知状态不伪造用户行为。可以明确指出后果与目标差距，同时保持耐心并吸收纠正，不能固定羞辱模板或每次从头盘问。未回复不等于未完成；提醒避免轰炸，严格程度可校准。在“自己试”的题目中不能借监督泄题；明确暂停／结束按范围生效，不以“为你好”越权继续。
- **产物：** 有来源的目标与计划版本、实际观察／推断区分、跨天监督记录、用户反馈前后行为对比、误判与过度提醒样例。语义及合适性由独立复核与实际试用评估，非字符串匹配即通过。
- **状态：** 未运行／未验收。

<a id="V-ExitReminderTimer"></a>

## V-ExitReminderTimer — 退出、提醒与真实时间

- **关联：** R20、R22、R36、R41；既有 A08/A14/A16/A17/A22，补传边界联 A31。
- **负责人／阶段：** backend 主责持久计时、提醒和取消，iOS/web 负责真机启停及通道状态，learning 负责请求范围、会话回应和紧迫性／重要性决策依据；QA 独立验收。P3，必要的采集停止保护在更早启用路径时即执行。
- **前置：** 已授权的提醒通道、可控测试时钟和真实设备；准备已学习时长／实际会话经过不同的休息请求，以及有真实截止时间、进度和用户目标依据的紧迫性／重要性对照；不预设用户固定休息策略或新的强制阈值。区分结束陪学、暂停提醒、暂停自主备课、停止单设备共享、撤销连接等请求，不合并成一个停止标志。
- **步骤：** 在不同已学习时长／会话情境下提出相同休息请求，记录系统实际回应和引用依据，不凭空推断疲劳或动机；退出后在已授权范围，分别改变事项紧迫性与重要性，观察提醒时机、强度／频率和措辞的实际调度决定与送达，核对其与真实计划／进度的关系。再改变视频播放速度并进行跳转，退出／重开应用，在不同设备查看计时；分别执行普通切 App、单路停止、显式结束、系统结束广播、主 App 强退及暂停／取消提醒；模拟离线、到期竞态、连接撤权和通道发送结果未知。
- **成功与负例：** 休息回应应有据联系已学习时长和会话经过，退出后提醒安排应有据响应真实紧迫性／重要性；对照中变化或保持原安排都要有可核对理由，不能只套固定回应／周期、从无回复推断未完成或臆造截止时间。时机与强度受用户实际暂停／授权范围约束，不靠任意固定阈值判通过。到期依据真实时间，持久恢复后不提前、重复或依赖视频进度；普通切 App 不误结束。明确停止实时采集后旧帧不冒充当前，重连不偷偷恢复采集。已授权的离线提醒与结束陪学范围分开；用户暂停／取消立即禁止相应后续动作。通道已发送不报已读，未知先核实；不支持的短信／社交渠道单列，不能用本地通知成功代替。

- **成功与负例：** 普通看课仍能适度主动、讨论及给可跳过检查，不被探索规则全局关闭；卡片默认安静，课程声不被当用户发言，用户只学习所选深入方向。图示／交互真实可复现，解释按需要展开且保留严谨性，不因固定短模板失去作用，也不承诺必然快速学会。“自己试”范围内不主动纠错／泄题，局部检查不升级完整解法；标题、补图、缓存及排队语音均受限制。沿用 §11：语音中断信号至客户端停止 P95≤300ms，待播内容取消；English-first 偏好及临时覆盖正确。
- **产物：** 实际课堂交互记录、触发及帮助范围依据、教学内容独立复核、演示可复现材料、跳过与越界负例、语音中断时间分布、实际用户能否独立继续的证据。
- **状态：** 未运行／未验收。

## V-SourceTimeRelations — 老师、画面、用户原话和笔迹的时间关系

- **关联：** R06–R10、R29、R46/R47；兼容 R51/R52/R59，既有 A01–A03/A06/A09/A12/A26/A27/A31/A42–A46。
- **负责人／阶段：** iOS/web 主责实际采集及输入，backend 主责事件／原档案时间关系，learning 主责引用和不确定性；QA 独立验收。P1 验证点读来源，P2 完整手写来源，P3 跨设备扩展。
- **前置：** 有人工参考时间线的真实课程片段，包含老师声音、字幕／黑板／图像区域、用户发言及手写；覆盖播放速度变化、跳转、页面重排、低置信符号和采集缺口。墨迹显示／用途／整理另执行 INTENT 五用例。
- **步骤：** 在视频继续播放时选择文字／公式／图像并讨论；记录用户说话与当时画面，书写后滚动／缩放／换题并重开；模拟缺音频、缺帧、离线补传和易混淆说话者，回查指定内容及之前的解释。
- **成功与负例：** 选择绑定指选当时的来源／帧／可靠视频位置，调整选区沿用标记时的完整快照，后续视频和当前新帧不改绑旧问题；墙钟、媒体位置及事件顺序不混淆。老师、用户、网页答案／批改和 AI 帮助分源，OCR/ASR 不确定保留原证据与缺口，不造历史。原稿及 AI 层独立，可编辑笔迹在原 §11 要求的落笔结束≤500ms 本地落盘；固定 100 次导航／点击／缩放／拖动播放／书写脚本不得误触 AI 查询并含真机检查。外部像素不冒充结构化墨迹；原位、冻结与画布结果分别报告，原位须核对 AI 实际收到叠加画面，不能从本地叠层可见推定成功。
- **产物：** 人工参考时间线及采集对照、来源／帧／视频锚点、说话者与反馈分类、墨迹保存／恢复证据、误触脚本与真机记录、缺失和错绑失败样例。

## V-MultiDeviceUnderstanding — 多设备共同理解当前活动

- **关联：** R19、R29、R32、R35、R36；工作屏关联 R05，兼容 R51/R52/R57，既有 A07/A12/A15/A16/A22/A31/A34/A38/A40。
- **负责人／阶段：** backend 主责统一会话及各路状态，learning 主责联合理解，iOS/web 各负责真实来源；QA 独立验收。P3 完成三设备联合上下文，P4 工作指令真实效果另见 V-WorkAgentActualAction。
- **前置：** 真实 iPad 课程、iPhone 相关先修材料和 Windows 工作画面同时可用，各路分别授权、可独立启停；准备过时画面、重复音频和无关活动作为负例。
- **步骤：** 在并行活动中询问当前课程难点、手机查阅的关联及工作进展；停止一路共享，改变另一设备的帮助／语言状态并引入短暂失联；切换来源、恢复连接，继续旧问题和提醒。
- **成功与负例：** 系统依据实际收到的独立来源正确解释设备间关系，相关查阅不误报走神，课程与工作不混源，重复音频不作重复用户发言。一路暂停不停止其他路；失联设备状态及旧帧明确过时，不能凭旧许可播出答案，重连不自动恢复已停共享。仅加入同一房间、保存多个 device_id 或连接同一账号不证明联合理解；提醒不重复，长期偏好与当前问题范围正确。
- **产物：** 同时设备操作记录、逐路采集／停止与新鲜度、跨源回答引用、重复音频处理、帮助状态同步／失联负例、提醒及跨设备记忆证据。
- **状态：** 未运行／未验收。
