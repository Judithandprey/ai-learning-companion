## Implemented and verified locally

- FastAPI routes use the owner schemas and OpenAPI: source register/read/version,
  atomic event ACKs, note CAS/read, usage, and cancellation. Authentication defaults
  fail closed. Explicit test tokens carry scope, expiry, actor and authorization
  generation, with checks repeated inside the repository transaction.
- One actor-scoped original archive with PostgreSQL storage/migrations. Source and
  frame hashes are checked on synthetic fixture ingestion. Source snapshots,
  frames, observations, note revisions and original artifacts are immutable.
  Exact URLs and query parameters are preserved; registration is not content fetch.
- Event ID/content and device-sequence conflicts roll back the whole batch. Server
  receive time does not affect replay equality. Out-of-order sequences get exact
  ACKs. HTTP keys are scoped to user/method/path and return committed original
  responses. Corrections retain original records and source/speaker provenance.
- Notes retain history and original ink; assistant changes cannot replace original
  blocks or context. Source deletion removes linked content and response-cache
  payloads, with source/event/note/request tombstones preventing stale recreation.
  Note reads check all evidence sources, including events outside context segments.
- Atomic 100,000 CNY-fen monthly reservations include all bounded attempts, use the
  server's America/Los_Angeles month and configured versioned price/FX bounds.
  Concurrent/repeated reservation and settlement are tested. Unknown outcomes hold
  exposure pending trusted reconciliation. Historical overages remain visible and
  block further reservations. No provider call exists.
- Worker begin/output commit check source and authorization generations under the
  same transaction as derived writes. Cancellation, deletion, revocation and source
  updates fence old work. Unknown job and budget reconciliation remain internal,
  evidence-bound operations; neither invents output nor retries external execution.
  Offline historical ingestion never enables live capture.

## Review and fixes retained

Independent local review reproduced four defects during implementation: reuse of
an erased event ID under another source, missing revocation checks for a note's
additional evidence, inability to clear a reconciled job's unknown status, and
failure to replay a completed job after budget settlement. All were corrected and
covered by regression tests before the final 195-test run. New contract integration
also corrected the provisional zero version to null and updated usage/receipt
formats; there is no alternate wire schema.
