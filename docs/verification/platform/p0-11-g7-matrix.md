Each row's `result` is a contract-0.1.0 `CapabilityResult`. 0.1.0 has no G7, so `result.gate` holds
the nearest 0.1.0 gate and `v1_1_gate` holds G7. The checker (`--matrix p0-11`) enforces these rules:
- a documentation claim is never recorded as implemented, compiled or verified on a device;
- `a44_status` stays within {candidate, unverified, unsupported, separate alternative} unless a device
  pass exists; A45-only rows and in-app alternative rows can never record an A44 pass;
- a forum post without an Apple reply is never labelled as an Apple statement.
