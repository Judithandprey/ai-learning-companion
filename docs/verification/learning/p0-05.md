## Fixed inputs and measurements

There are 90 source snapshots, 89 synthetic SVGs and 875 observations. Thirty
primary scenes have two distractor episodes each; 600 additional repetitive
later observations exercise retention. Five scenes include explicit corrections.
The score set contains **50 exact + 30 fuzzy/correction queries**; six separate
development queries are retained. No parameter tuning or answer-driven ranking
change was performed. Labels were separately authored before scoring but have
not been independently reviewed by a human.

A correct hit must match all of user, source, source version, event and frame.
Complete-query success requires *every* expected anchor in Top-5. Mean evidence
recall reports partial retrieval separately. Finding the same words from another
course, actor or version is not counted as correct evidence.

| Candidate | Exact complete / n | Fuzzy complete / n | Fuzzy mean evidence Recall@5 | Exact P50 / P95 ms | Fuzzy P50 / P95 ms |
| --- | --- | --- | --- | --- | --- |
| Lexical only | 50/50 | 17/30 | 70.00% | 1.207 / 1.567 | 1.270 / 1.882 |
| Lexical + explicit metadata | 50/50 | 25/30 | 83.33% | 1.036 / 1.305 | 1.071 / 1.302 |

These are final-run in-process search timings, one measured query execution per
candidate (50 exact, 30 fuzzy). They exclude original loading/validation
(277.315 ms) and index build (28.904 ms). Hardware caching, small synthetic corpus
and structured filters constrain interpretation; this is not a service/UI latency
or real-course result. Both candidates receive the same text and metadata; the
ablation intentionally ignores optional metadata filters. The baseline contains
no vector search or learned semantic component.

The exact fixture target of >=95% evidence Recall@5 is met **on this synthetic
set only**. This does not establish unique answer correctness: some repeated
phrases remain ambiguous among dates, and Top-5 may include distractors.
