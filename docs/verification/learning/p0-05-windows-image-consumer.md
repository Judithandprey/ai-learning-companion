## Outcome and boundary

Existing supplied/stored process context and observation windows accept an
explicit optional `windows_resolver` keyword. Windows metadata/bindings validate
all declared image references before any bytes, including metadata-omitted items.
The Windows callable gets the exact full descriptor with literal raw/composed
role and a bounded byte limit; successful results must echo both. Existing
non-Windows resolver signatures/results are unchanged. The PNG checker is reused
for both images, with no new decoder, source store, protocol or framework.

Raw remains under `item.image`; Windows adds a separately labelled
`composed_image`, including explicit absence. Hash/length/dimensions/type/PNG
structure checks apply independently. Per-image gaps cannot fall back to the
other role. Both payloads count toward total bytes even for identical shared
artifact aliases. Metadata reserves both results and excludes only their binary
payloads. Window comparison distinguishes raw/composed bytes and otherwise keeps
unknown clocks, chronology, meaning and reasoning. Full descriptor/sample/source
and separate editable-ink references remain untouched. A rendered composition is
not editable-original preservation, acquisition authority or AI receipt.
